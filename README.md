# RustWASM


Rust + WASM apps compiled to a single html file.  Each folder is its own app. Instantly port apps from windows to linux to mac. All you need is a modern browser and you can run the html file. How i roll... ALL apps can run on any os offline too, it just needs a modern browser. ONE self contained, complete app per html file. They can run offline, too, proof that they do NOT call on any external resources from different sites. 

Featured app... check out /ecosystem. Very complex and interesting app for being in a single html file .
