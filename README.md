# RustWASM


Rust + WASM apps compiled to a single html file.  Each folder is its own app. Instantly port apps from windows to linux to mac. All you need is a modern browser and you can run the html file. Some apps can run on any os offline , some of the apps need a web server to run locally on a port but that is super easy to do. 

Featured app... check out /ecosystem. Very complex and interesting app for being in a single html file .
