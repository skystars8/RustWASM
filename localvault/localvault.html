How your files are protected Algorithms, key derivation, and file format

LocalVault uses reviewed, authenticated primitives with fixed parameters. It does not send files, passphrases, keys, or usage data to a server.

Encryption
XChaCha20-Poly1305 authenticated encryption
Passphrase derivation
Argon2id · 64 MiB memory · 3 iterations · 1 lane
Processing
Independent authenticated 4 MiB chunks
File format
LocalVault format v1 with a fresh random salt and nonce sequence per file

LocalVault cannot reset or recover a passphrase. Keep a secure copy somewhere other than with the encrypted file.
